# Publication notes

WildScape is being preserved as a public-source candidate.

Current scope: Python GIS pipeline, TypeScript terrain/species explorer and optional team workspace. Includes a deterministic offline fixture.

Preparation still required: Choose a project license; package the synthetic/offline fixture first. Review attribution and redistribution metadata for bundled terrain, imagery, occurrence data and images. Exclude raw/generated data, private databases, backups and production settings. Inspect public/ and worlds/ explicitly because the root ignore rules do not exclude them.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
